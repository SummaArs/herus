# HERUS Symbiont v2

This directory is an experimental, host-independent capability runtime.

## Research loop

`observe -> infer transition -> collect evidence -> learn model -> compose -> verify -> transfer`

## Current scope

- Dependency-free Python research prototype.
- Explicit `HostAdapter` boundary.
- Signed-by-construction observations using deterministic digests.
- Evidence-backed transition model.
- Candidate-to-verified skill promotion.
- Experimental transfer by matching observed effect signatures.
- Runtime audit snapshot.

## Non-claims

This is **not** an AGI implementation, not a safety-certified controller, and not yet a general robot learning system. The current transition model is intentionally discrete and scalar; it does not yet represent continuous dynamics, partial observability, uncertainty distributions, causal structure, language grounding, or robust morphology transfer.

No code generated by a host or language model is executed by this package. Physical adapters must add independent authorization, rate limits, emergency stop, resource constraints, and hardware-specific validation before any real actuator is connected.

## Next validation gates

1. Add deterministic simulator hosts with different action names but equivalent effects.
2. Add hidden tasks and adversarial contradictory observations.
3. Measure discovery cost, transfer success, false promotion, and abstention.
4. Replace exact effect matching with typed effect schemas and uncertainty intervals.
5. Integrate the existing HERUS Semantic IR only through a proposal boundary.
6. Add property-based and mutation tests before opening a PR.

The project should claim only what is supported by versioned code, hidden tests, measured cost, and negative results.
